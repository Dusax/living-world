# Mundo Vivo

Uma vila em pixel art que cresce sozinha: cada seguidor vira um morador com ficha de D&D, a IA decide o dia a dia e você é o deus que interfere.

Tudo está em [`living-world/`](living-world/). Para jogar:

```bash
cd living-world
npm start      # http://localhost:8080
npm test
```

Veja [`living-world/README.md`](living-world/README.md) para o jogo, as mentes de IA gratuitas e a estrutura do código.
